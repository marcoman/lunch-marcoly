# Greetings
Hi there!

This repository is a collection of examples that are meant to help you see specific items quickly and efficiently.

To the best of my ability, I'm trying to provide examples in two forms:
1. Single/simple "Unit" examples.  These are for single features.
2. Complex/combined "Use Case" examples.  These are for common use cases.

I used AI agents to generate a lot of the content here.  Where I spend the majority of my team is adding finesse to the examples so they are easier to read and use.

# Recommended workflow

Start by reviewing the reference application.  This one is free from any enhancements and represents a basic application.  The goal would be to get familiar with the essential behaviors.

Next, review the different top-level directories of the examples.  Each example is a variation of the reference.  Most examples exercise the same attributes, but in slightly different ways.  The goal is to show you how LaunchDarkly's capabililties map into simple applications so you can see one possible implementation at a time.  The intention is to start operations as the reference application, and then see how each example adds.

Notice how each example arrives in different language flavors.  I am starting with the more popular languages and I'm apt to add a few more as the demand requires it.  The applications run as a console or web applications.  You may find the console application fairly efficient.

The provisioning scripts use REST or terraform.  In most of my testing, I've relied on REST because they are simple, fast, and don't have many dependencies.
