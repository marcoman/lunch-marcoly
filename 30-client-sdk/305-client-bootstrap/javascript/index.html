What this teaches

Bootstrap passes flag values into the client at initialize, so the first paint is not the code default. This lab holds that paint for 8 seconds and counts down, which simulates a startup delay. At 0, the live evaluation replaces it.

The Bootstrap tab shows the SDK calls, the paint line, and the context that was sent.

Try it
  1. Log in. The grid shows the bootstrap paint while a countdown simulates a startup delay.
  2. At 0, the paint line says whether the stream matched. The log already recorded ready.
  3. Turn highlight off and log in again. Bootstrap stays through the countdown, then the stream corrects it.
