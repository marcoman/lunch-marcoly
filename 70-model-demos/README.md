# 70-model-demos

Fun apps that call a vision or text model and show the result. Each child is one product. LaunchDarkly chooses the model and, later, a judge or a tool. These apps are not the equity briefing in [20-agent-config](../20-agent-config/) and not the grid in [99-use-cases](../99-use-cases/).

The series owns global number **70**. Children are `01`, `02`, `03`, … inside this folder, same pattern as `99-use-cases`. That can pass ten without using `71`–`79` or colliding with another series. **80** stays the next free decade.
