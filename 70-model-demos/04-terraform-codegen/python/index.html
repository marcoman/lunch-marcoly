Run comparison

Terraform validate is the result that matters. Lower is better for time, input tokens, total tokens, and validate issues. Pass beats fail. Generated resources closer to 13 and generated descriptions closer to 11 win. Lines and output tokens have no winner. Cost appears when a model config has a price. A tie stays plain.

Generate once. Each selected model keeps its own sent and received record, including the judge.

One Generate evaluates terraform-codegen-compare for each checked model, writes main.tf, and runs terraform validate. A separate judge config, terraform-codegen-judge, then scores that file with Sonnet. Pass and fail files are both scored. The score does not rewrite the file.
