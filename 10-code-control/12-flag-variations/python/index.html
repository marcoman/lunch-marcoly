What this example is

This example teaches LaunchDarkly variation types on the grid navigator: boolean (anonymous context), string, number, and JSON.

What we show

Log in, move on the grid, and use Controls to change targeting via the REST API. Context shows the user vs anonymous evaluation contexts. The bottom Trace dock logs each change.

Flag keys

show-anonymous-host-os-emoji — boolean gate; app maps private hostOs → emoji on an anonymous context.
configure-navigation-count-label — string fallthrough for the counter label.
configure-lucky-number — number fallthrough for Lucky Number is: N.
configure-max-navigation-moves — JSON fallthrough {"maxMoves":N} caps moves.

Why it matters

One ship, many variation shapes — product can change labels, numbers, and JSON config without a redeploy. Keywords: string variations, number variations, JSON variations, anonymous contexts, private attributes, semantic patch.
