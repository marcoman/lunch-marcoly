What this teaches

A scheduled change asks LaunchDarkly to turn the highlight on at a future time. The app resets the flag off, replaces any pending schedule, then waits. The browser re-evaluates the SDK value. It does not flip the highlight with its own timer.

The Schedule tab shows the delay, the elapsed clock, and the variation that came back.

How to run it
  1. Choose a delay. One minute is the short demo.
  2. Start the scheduled change. The highlight returns to none immediately.
  3. Watch elapsed time. Green usually arrives a little after the selected delay, because LaunchDarkly executes close to that time, the change has to reach the SDK, and this page re-evaluates every two seconds.
  4. Stop cancels the pending change, turns the flag off, and holds the clock.

Scheduled flag changes are a LaunchDarkly Enterprise feature.
