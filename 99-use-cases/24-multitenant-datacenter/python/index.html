    About

    One size row is one multi-context. The datacenter picks the border, the replica picks the fill, and the customer size picks the four icons. The rolling deployment is a separate clock. The customer panel waits for both the roll and the flag. A border palette and the service fill also show on the customers they match. With those flags on, that is every customer.

    Start a deployment and watch one datacenter finish before the next. All capabilities walks each build to the end, then starts the next. Immediate deploy skips the wait and leaves the flags off. Reset on that tab returns every rollout to not deployed. On Flags, check a size and a datacenter. Large customers have one replica, and ENZO in us-west-1 keeps two. BLEU NUAGES and the other EU customers stay off for data sharing and marketing.
