      What this example is

      A small stand-in for many single tenants spread across datacenters. Each presence is its own evaluation. Two flags style every box the same way: a border palette, and a fill of that same hue.

      How the names are made

      Walk A–Z twice. Vowels are Large. Q and Z are unknown. Every other letter uses (letter number − 1) mod 3: 2 is Medium, and 0 or 1 is Small. Each size keeps its own counter. Odd and even are that counter. An odd Small is size 1 in one datacenter. An even Small is size 2 in two. An odd Medium is size 5 in one. An even Medium is size 5 in three. An odd Large is size 7 in three. An even Large is size 7 in all five. Unknown stays size 3 in one. One cursor hands out the next datacenters and wraps after DC05. The same name is drawn in each datacenter that customer occupies. The subscript is size.version, and every instance starts at 0, so a large reads 7.0.

      What to look at

      Read a datacenter card. The Flags tab turns the border palette on and picks the fallthrough. The fill rollout is a progressive rollout on tenant-box-fill: five one-minute steps, then everyone. Start that rollout in LaunchDarkly. Reset on the Flags tab returns the flag to Empty. Trace records those changes. Model lists the segments and what comes later.
